# Владислав Нижник · Аналитик данных

Портфолио: **https://ganra3ev.github.io/**

Четыре кейса, схемы анализа, навыки и контакты. Статический сайт на HTML, CSS и JavaScript, без сборки и серверной части.

## Файлы

- `index.html` — страница портфолио.
- `style.css` — адаптивное оформление, Unbounded и Manrope, три цвета.
- `app.js` — разборы кейсов, переключатели схем и копирование почты.
- `assets/data-signal.webp` — авторская иллюстрация, созданная с ImageGen.
- `.nojekyll` — публикация готовых файлов без обработки Jekyll.

## Публикация

GitHub Pages публикует корень ветки `main`. После коммита в `main` сайт обновляется автоматически.

Для локального просмотра откройте `index.html` в браузере или используйте любой статический HTTP-сервер.

## Содержание и ограничения

Коммерческий кейс BeanFlow отделён от трёх проектов портфолио. Графические схемы иллюстрируют методы и не выдают условные данные за результаты расчётов. Подробные ограничения находятся внутри разборов кейсов.

Контакты открывают Telegram или почтовое приложение. Сайт не сохраняет сообщения и не использует счётчики посещений. Шрифты загружаются из Google Fonts, с системным резервным шрифтом.
